# 📦 Recursos & Versión Standalone (.exe)
**Autor:** [Iamfreedz](https://kick.com/iamfreedz)  
**Canal Oficial:** [https://kick.com/iamfreedz](https://kick.com/iamfreedz)

En esta carpeta se encuentra la versión precompilada en binario ejecutable (`.exe`) lista para Windows 10 / 11 de 64 bits.

---

### 🚀 Archivos disponibles en esta carpeta:
* **`IRL_Server.exe`**: Servidor RTMP y consola web empaquetados en un único archivo.
  * No requiere instalar Python, pip ni librerías adicionales.
  * Al ejecutarse por primera vez:
    1. Extrae automáticamente la carpeta `obs_plugin/` con los scripts para OBS Studio.
    2. Crea un acceso directo en tu Escritorio: `IRL Stream Server`.
    3. Inicia el servidor RTMP en el puerto `1935`.
    4. Abre la Consola Web en tu navegador: `http://localhost:8080`.
* **`INSTRUCCIONES_PORTABLE.txt`**: Guía rápida paso a paso para usuarios finales.
